# Interactive content

Data-driven: `InteractiveDefinition` (validated JSON, `packages/validation`) → renderer (`apps/mobile/src/features/interactive`) → student interaction → `interaction_completed` event (the `interaction_results` table is reserved for server-validated results; not yet written) → learner model.
Adding an experience = a new `kind` in the schema + a renderer branch; no new screen.

| kind                                                                                                                                                                                                                                                                                                  | Schema                                                                         | Mobile renderer                                          | Learning signal                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------- | --------------------------------- |
| tap_reveal                                                                                                                                                                                                                                                                                            | items{label,reveal}                                                            | ✅                                                       | completion (all revealed)         |
| ordering                                                                                                                                                                                                                                                                                              | items + permutation `order`                                                    | ✅                                                       | score = positions correct         |
| matching                                                                                                                                                                                                                                                                                              | left/right/pairs                                                               | ✅                                                       | score = pairs correct             |
| timeline                                                                                                                                                                                                                                                                                              | events{year,label,detail}                                                      | ✅ (read-only sorted)                                    | —                                 |
| map                                                                                                                                                                                                                                                                                                   | `viewBox`, regions{id,name,path (SVG path data, whitelist regex),capital,info} | ✅ react-native-svg, tap → name/capital/info             | completion (all regions explored) |
| diagram                                                                                                                                                                                                                                                                                               | mediaId + hotspots                                                             | schema only; renderer says media pipeline not configured | —                                 |
| Maps are educational objects (regions are data with names/capitals/info), vector-based, no proprietary map SDK. `map_based` questions reference `interactiveId` + `regionId` answer (schema + grading done; question UI shows the truthful "unsupported" message until the map-question UI is built). |
| Seed includes a tap_reveal example; **no real border geometry is shipped** (accurate boundaries need an open, licensed dataset recorded in the source registry).                                                                                                                                      |
| Note: current mobile scoring events are _not_ mastery evidence (server only credits graded answers). Server-side validation of interaction results for mastery is future work.                                                                                                                        |
