- Return ONLY valid JSON (double quotes, no comments, no trailing commas). No explanations, no markdown, no extra words.

IF THE APP SAYS SOMETHING IS WRONG
- "not valid JSON": the AI added extra words or missed a quote/comma. Tell it: "Return only valid JSON."
- "Item 12: answer does not match any option": that question's answer letter is wrong. Fix it or ask the AI to correct item 12.
- "You reached your posting limit": wait a while, then import the same file again and type the item number the app showed in "Start from item number".
- Limits: max 5000 questions and 5 MB per file. Your account (trusted creator) can import about 1000 posts per hour.
